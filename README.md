# Product Returns & Refund Analysis

## Business Question
**Why are products returned and what does it cost?**

## Objective
Analyze e-commerce product returns, identify common return reasons, and understand refund costs using data analysis.

## Tools Used
- Python (Pandas, Matplotlib)
- MySQL
- Power BI

## Dataset
The project uses four synthetic datasets: Orders, Returns, Products, and Customers.

## Project Work
- Data cleaning and preprocessing
- SQL queries and analysis
- Exploratory Data Analysis (EDA) and visualizations
- Interactive Power BI dashboard
- Business insights and recommendations

## Key Finding
Size/Fit Issue is the most common return reason, accounting for 591 returns (18.47%).

## Outcome
The analysis helps identify return patterns and supports data-driven recommendations to reduce product returns and refund costs.

**Note:** The dataset is synthetic and intended for educational and portfolio purposes.
